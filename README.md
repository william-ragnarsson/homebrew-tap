# william-ragnarsson/tap

Homebrew formulas by William Ragnarsson.

## Wallpaper Headlines

Today's news front page as your desktop picture, from a menu bar app.

```sh
brew install william-ragnarsson/tap/wallpaper-headlines
wallpaper-headlines
```

It builds on your Mac, so it needs the Command Line Tools (`xcode-select --install`)
and macOS 14 or later. Update it from the app's Settings, or with
`brew upgrade wallpaper-headlines`.
